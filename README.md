# AI-Powered Automatic Block Planning for Indian Railways

Smart India Hackathon (SIH) project — an AI-powered system to automate block
planning and maximize asset availability for train operations on Indian
Railways.

## Problem Statement
Automatic block planning to maximize asset (track/block) availability for
train operations, using AI/ML-based scheduling and optimization.

## Tech Stack
- Frontend: React
- Backend / ML: Python

## Project Structure
```
/frontend   -> React app
/backend    -> Python backend / optimization logic
```
